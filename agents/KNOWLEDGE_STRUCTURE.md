# Knowledge Structure

## Subject Categories
The project is built around 6 main subjects:
- **Backend Engineering**
- **DevOps**
- **System Design**
- **Operating System**
- **DBMS**
- **Computer Network**

## Versioning Hierarchy
Inside each subject, maintain a clean versioned folder structure:
- **Version 1 (Original)**: Initial, foundational notes.
- **Modern Version 2**: Current, updated knowledge.
- **Version 3 (Raw Transcripts)**: (Specific to Backend Engineering) Raw data and primary sources.

## Sidebar Configuration
Use `_category_.json` in each directory to ensure:
- Labels are accurate and user-friendly.
- Emojis are used for visual clarity.
- The sidebar order is logical and intuitive.
